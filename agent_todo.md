## Légende

### Priorité
- 🔴 **Haute** : impact SEO significatif, traiter en premier
- 🟡 **Moyenne** : impact modéré, planifier sous 30 jours
- 🟢 **Faible** : amélioration optionnelle

### Risque SEO (si inaction)
- **Élevé** : perte de positions probable
- **Moyen** : dilution d'autorité, performances sous-optimales
- **Faible** : impact limité mais optimisation possible

### Confiance de l'analyse
- **Élevée** : ≥ 3 signaux concordants (title + H1 + contenu + maillage)
- **Moyenne** : 2 signaux forts ou 1 fort + 2 moyens
- **Faible** : 1 signal ou données incomplètes

### État d'exécution
- ⏳ **En attente** : validation non encore reçue
- ✅ **Validée** : utilisateur a confirmé, prête à exécuter
- 🔄 **En cours** : exécution en cours
- ✔️ **Terminée** : action complétée avec succès
- ❌ **Refusée** : utilisateur a refusé cette action
